# Cómo instalar la extensión de Creiai Cinema (host)

Solo necesitas la extensión si vas a **compartir pantalla** (ser host). Los que solo miran entran a la web directamente.

## Pasos

1. **Descargar** `cinema-extension.zip` desde la web (botón "Descargar extensión").

2. **Descomprimir** el ZIP:
   - Windows: clic derecho → "Extraer todo"
   - Mac: doble clic
   - Guarda la carpeta en un lugar fijo (ej. Documentos). No la borres.

3. Abre Chrome y escribe en la barra de direcciones: `chrome://extensions`

4. Activa **"Modo de desarrollador"** (interruptor, arriba a la derecha).

5. Clic en **"Cargar descomprimida"** → selecciona la carpeta `cinema-extension`.

6. Clic en el icono 🧩 de Chrome → fija (pin) la extensión Creiai Cinema.

7. Para compartir: abre la película en una pestaña → clic en el icono Creiai Cinema → escribe el código de sala → "Compartir".

## Notas

- Solo Chrome / Edge / Brave (Chromium).
- El aviso "extensión en modo desarrollador" es normal.
- No funciona con Netflix, Disney+, HBO (DRM).
- Para actualizar: descarga el ZIP nuevo, reemplaza la carpeta y pulsa ↻ en chrome://extensions.
